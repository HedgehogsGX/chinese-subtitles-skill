# osu! 游戏术语中英字幕词典

> [!info] 用途
> 本表面向英文 osu! 视频的简体中文字幕翻译。它不是“梗百科”：正文优先给出清楚、稳定的字幕译法，同时单列中国大陆玩家常用的简称、口语和社区说法。社区用语会随圈子、模式和年代变化，翻译具体台词时仍应结合画面与语气。

## 使用原则

1. 游戏名写作 **osu!**，不要写成全大写的 “OSU”，除非是在照录原视频文字。
2. 四个正式模式名通常保留为 **osu!、osu!taiko、osu!catch、osu!mania**。需要帮助观众理解时，可在首次出现时补充“主模式、太鼓、接水果、下落式”。
3. 首次出现缩写时可写全称，例如“表现分（pp）”；之后直接保留 `pp`、`FC`、`DT` 等社区高度熟悉的缩写。
4. `beatmap` 首选“谱面”，口语可简称“图”；除非原话确实在谈空间地图，否则不要译成“地图”。
5. `mod` 有三种常见含义，必须看上下文：
   - 游戏机制：**模组**，如 `Hidden mod`；
   - 给谱面提修改意见：**摸图 / 谱面审阅**，如 `modding a map`；
   - `moderator` 的简称：**管理员**。
6. `standard` 与 `stable` 不同：`standard/std` 通常指 osu! 主模式，`stable` 指旧客户端版本。
7. 表内“社区说法”适合翻译玩家对话、直播和弹幕；教程、采访、新闻与正式解说优先使用“字幕首选”。

## 14. 最容易误译的词

| 英文词 | 容易误译成 | 应如何判断 |
|---|---|---|
| standard | 稳定版 | `standard/std` 多半是主模式；`stable` 才是稳定版客户端。 |
| map | 地图 | osu! 语境通常是“谱面 / 图”；作动词时是“作图”。 |
| mod | 修改 | 看它是游戏模组、谱面审阅，还是管理员简称。 |
| rank | 排名 | `rank a map` 是“让谱面上架”；`player rank` 才是玩家排名。 |
| difficulty / diff | 游戏有多难 | 也可能专指谱面集里的一个“难度文件”。 |
| jump | 跳跃 | standard 是空间大跳；mania 是同一时刻的双押。 |
| stream | 流 | standard 常译“串 / 连打”；mania 需按键型译“切换、乱键或多押流”。 |
| slider | 滑块 | standard 为“滑条”；mania 的 LN 虽可由 slider 转换而来，但字幕应叫“长键”。 |
| 300 | 满分判定 | standard 的 300 是最高常规判定；mania 上面还有 MAX / 彩 300。 |
| accuracy | 精准 | 游玩数据通常是“准确率 / 准度”；pp 组件的官方术语中 `aim` 是“精准”，`accuracy` 是“精确”。 |
| free | 免费 | `this map is free` 是“这图很简单 / 白给”；`Free Mod` 才是自由选模组。 |
| choke | 窒息 | osu! 中是临近目标时意外失误，常译“痛失 FC / 最后断了”。 |
| tail | 尾巴 | standard 可指滑条尾；mania 可指长键尾；`tail choke` 是结尾失误。 |
| bracket | 括号 | 比赛中是对阵表；mania 7K 等语境中是一种交叉多押键型。 |
| host | 主机 | 多人房间是房主，赛事语境可指主办。 |
| client | 客户 | 指游戏客户端。 |
