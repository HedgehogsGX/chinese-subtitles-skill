# Apex Legends 游戏术语中英字幕词典

> [!abstract] 用途
> 本词典面向 **Apex Legends 英语视频的简体中文字幕制作**。正文优先采用游戏简体中文、EA 官方中文和稳定的中国大陆玩家用语；身法、战术与竞技黑话另列社区说法。截至 **2026-07-30（赛季 29「超频风暴」）**。

> [!warning] 官方译名、社区说法与字幕补译
> “字幕首选”优先使用国际版游戏简中。EA 只公开繁中而未公开简中时，转写为简体并保留官方用词；没有公开官方中文的 HUD 小地点会给出 **字幕建议译名**，并在说明栏明确标注“非官方”。人名、战队名和玩家名原则上保留原拼写。

## 字幕使用原则

1. 游戏名首选 **Apex Legends**；需要中文时写 **《Apex 英雄》**，不要写成“顶点传奇”。
2. `Legend` 按游戏角色译为“英雄／传奇”，具体角色一律采用游戏简中名；`legendary` 作为稀有度时译“传奇”。
3. 首次出现缩写可写全称，例如“兴趣点（POI）”“排名分（RP）”；后文直接保留 `POI`、`RP`、`KP`、`TTK`。
4. 身法专名不强行意译。首次出现可写“tap-strafe（蹬墙式空中急转／滑轮急转）”，之后保留英文或中文圈稳定叫法。
5. `revive` 是扶起倒地队友，`respawn` 是让已淘汰队友重返比赛；分别译“救起／扶人”和“重生”，不得混用。
6. `shield` 是护盾，`armor` 是护甲，`health` 是生命值；玩家口语“大电、小电、大药、小药”只适合直播与队内语音。
7. 表内“社区说法”用于直播、弹幕和玩家对话；教程、新闻、采访和机制说明优先用“字幕首选”。
8. 版本会改变英雄职业、技能、地图、辅助手段和数值。涉及具体伤害、冷却或当前轮替时，应再次核对当期改版资讯。

## 3. 身法与移动（重点）

> [!important] 身法字幕规则
> `movement` 在 Apex 玩家语境中通常不是泛泛的“移动”，而是“身法／移动技巧”。基础动作采用中文；社区技术名首次出现保留英文并补中文解释，后续可直接写 `tap-strafe`、`superglide`、`wall bounce`。

## 12. 最容易误译的词

| 英文词 | 容易误译成 | 应如何判断 |
|---|---|---|
| movement | 普通移动 | 玩家夸某人的 `movement` 时通常是“身法”；设置或机制总称才是“移动”。 |
| revive | 重生 | 倒地但未淘汰时是“救起／扶人”；`respawn` 才是淘汰后重生。 |
| armor / shield | 一律写护甲 | 数值池正式写“护盾”；玩家口语“甲”可保留。 |
| crack | 裂缝 | 战斗报点是“破甲／击破护盾”。 |
| flesh | 肉 | 报点中表示目标已无护盾，应译“打到肉身／无盾”。 |
| one shot | 精确剩一发伤害 | 玩家常用来夸张表示“大残”，字幕不宜承诺精确血量。 |
| cell / battery | 电池芯／汽车电瓶 | 分别是“小型护盾电池／护盾电池”，口语“小电／大电”。 |
| rotate | 旋转 | 大逃杀战术中是“转移／转点／运营”。 |
| zone | 区域 | 多数比赛语境是“安全区／圈”；技能范围才是普通区域。 |
| ring | 戒指 | 是安全区圆环或毒圈。 |
| third party | 第三方机构 | 是介入交战的第三支小队，常译“劝架”。 |
| ape | 猿猴 | 作动词是“不顾代价强冲”。 |
| rat | 老鼠动物 | 排位语境是隐藏求生的独狼或“苟分玩家”。 |
| thirst | 口渴 | 是优先补掉倒地敌人。 |
| grief | 悲伤 | 竞赛中常指损人且未必利己的干扰。 |
| beam | 光束 | 作动词是“连续精准命中／一梭子融掉”。 |
| stick | 棍子 | 手榴弹语境通常是电弧星黏中目标。 |
| scan | 扫描仪 | 作动词是扫描并揭示敌人。 |
| ult / ultimate | 最终的 | 英雄技能应译“绝招／终极技能／大招”。 |
| Q | 字母 Q | 键鼠语境常代指英雄战术技能。 |
| passive | 被动消极 | 指“被动技能”。 |
| tactical | 战术性的 | 作为技能类别写“战术技能”。 |
| legend | 传说故事 | 指可操作角色时写“英雄／传奇”。 |
| legendary | 传奇人物 | 装饰品或物资语境是“传奇稀有度”。 |
| knock | 敲门 | 战斗中是“击倒”。 |
| finish | 完成 | 对倒地敌人通常是“补掉／处决”。 |
| reset | 重置游戏 | 战斗中是补状态、扶人并重新组织。 |
| swap | 交换 | `armor swap` 是“换甲”。 |
| anchor | 锚 | 队伍职责是守后点和支撑枪线的“后点／架枪位”。 |
| IGL | — | 场上指挥，不是战队经理。 |
| AA | 防空炮 | 手柄讨论中通常是辅助瞄准（aim assist）。 |
| roller | 滚筒 | Apex 社区常指手柄玩家。 |
| config | 普通设置 | 身法语境可能指自动化配置脚本，需说明合规风险。 |
